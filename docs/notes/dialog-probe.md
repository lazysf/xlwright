# マクロの実行中のダイアログの見分け方と文字の読み方

[設計](../architecture.md#失敗の返し方と記録)の段階1の未確認「非表示の専用のExcelがマクロの実行中にダイアログで止まった時を見分けられ、その文字を読めるか」の記録です。
捕まえないエラーで止まった時は、ダイアログを見張って文字を読んで返す、と人が判断しました（[マクロの実行](../architecture.md#マクロの実行)）。

## 版

- Windows 11 Pro 10.0.26300、.NET 10.0.14（x64）
- Microsoft 365 Excel 64-bit 16.0.20527.20112
- `AccessVBOM`は1、`VBAWarnings`は2
- 起動した場所: Claude Codeのデスクトップアプリの会話のシェル（Git Bash）から起動した`dotnet`

## 再現の手順

```powershell
dotnet build spikes\sta-com -c Release
dotnet spikes\sta-com\bin\Release\net10.0-windows\StaCom.dll vba
```

[VBAの反映とマクロの実行](vba-run.md)の試行`vba`に、次を加えました。

- MsgBoxを出すマクロ（題名と本文は日本語）を実行するセッション。
- マクロの呼出しの間、見張りのスレッドが250 msごとに、所有を確定したEXCELのプロセスのトップレベルのウィンドウを列挙する（[見張り](../../spikes/sta-com/DialogProbe.cs)）。ダイアログを見つけたら、その題名と、表示された`Static`・`Button`の子ウィンドウの文字を`WM_GETTEXT`（1つ50 ms、合計500 msまで）で読み、すぐに所有を確かめた時のハンドルで終了させる。見つからなければ、時間を過ぎた時に終了させる。

ダイアログの見つけ方は、2つを順に試しました。

1. 設計の規則: 無効な`XLMAIN`があり、表示されて有効なウィンドウの所有者を辿ると、その`XLMAIN`に届く。
2. 代わりの規則: 同じプロセスの`XLMAIN`のどれかが無効で、同じプロセスに、表示されて有効な`XLMAIN`以外のウィンドウがある。

止まり方は4つです。0で割る実行時エラー、宣言の無い変数のコンパイルエラー、MsgBox、ダイアログを出さない終わらないマクロ。試行を3回実行しました。

## 判定

### 設計の規則（所有者を辿る）

不一致。3つのダイアログのどれも、この規則では見つからなかった。

- 実行時エラーとMsgBoxのダイアログ（`#32770`）には、所有者が無かった。
- コンパイルエラーのダイアログ（`#32770`）の所有者は、VBEのウィンドウ（`wndclass_desked_gsk`、表示されて無効）で、VBEのウィンドウには所有者が無かった。

### 代わりの規則（無効な`XLMAIN`と、表示されて有効なウィンドウ）

支持。3つのダイアログのすべてを、最初の見張り（呼出しから255〜270 ms）で見つけた（3種類を3回ずつ）。

- ダイアログで止まっている間、ブックの題名を持つ`XLMAIN`（非表示）は無効だった。題名の無いもう1つの`XLMAIN`（非表示）は有効だった。
- 終わらないマクロでは、`XLMAIN`はどちらも有効で、表示されたウィンドウは無かった。ダイアログと見誤らなかった（3回）。

### 文字の読み方

支持。3つのダイアログのすべてで、題名と本文を2 ms以内に読めた。

- 実行時エラー: 題名「Microsoft Visual Basic」、本文「実行時エラー '11': 0 で除算しました。」、ボタンの「継続」「終了」「デバッグ」「ヘルプ」。
- コンパイルエラー: 題名「Microsoft Visual Basic for Applications」、本文「コンパイル エラー: 変数が定義されていません。」、ボタンの「OK」「ヘルプ」。
- MsgBox: マクロが渡した題名と本文、ボタンの「OK」。

ダイアログを見つけて終了させると、マクロの呼出しは約280 msで`0x800706BE`で戻った。

## 後始末とGit差分

- 3回の実行の後、どれもEXCELのプロセスは0だった。実行の前からあったプロセスは無かった。終了させたのは、見張りが、所有を確かめた時のハンドルで終了させたExcelだけです。
- `.xlwright/spikes/vba/App/`は、各実行の最後に消した。
- 読んだ文字は、試行のソースに書いた文字とExcelのエラーの文字だけで、実験の画面の出力にだけ出した。
- Gitで管理するブックには触れていない。
- Gitの差分は、実験の見張りの追加と、本書の追加と、設計・ROADMAP・TODO.mdの更新だけです。
