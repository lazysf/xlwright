# 配布ブックの出力

コマンド例の `<skill>` は、SKILL.md に書いたこのスキルのフォルダの絶対パスに置き換える。

VBA をロックした配布用のブックを出力する。閉じたブックをバックアップしてから、操作可能な Windows デスクトップで実行する。VBA の取り込みと保護の確認には `AccessVBOM` が必要なので、SKILL.md の「作業前の確認」に従う。実行中は Excel と VBE が表示されるため、先に一言伝え、処理が終わるまで表示されたウィンドウを操作しない。

```powershell
powershell.exe -NoProfile -File "<skill>/scripts/Publish-Workbook.ps1" -Path <ブック> -OutDir <出力先>
```

ブックのフォルダの `vba/`（必須）と、あれば `ribbon/customUI14.xml` を、一時コピーに順に反映する。その内容を配布用に複製し、VBE の「プロジェクトを表示用にロックする」を設定する。パスワードは出力ごとに生成し、表示・記録しない。配布用コピーを保存して開き直し、ロック済みと確認できてから、作業ブックと配布先を更新する。取り込みやロックに失敗した場合は、元のブックと配布先を更新せずに終了する。

作業ブックは VBA を編集できる状態で更新する。配布後の修正も作業ブックと正本から行う。VBE のロックで制限するのは、Excel 上での VBA の閲覧・編集。配布時の保護は VBA プロジェクトに限る。ブック構成も保護する場合は、シートの表示切り替えなど、マクロが行う操作を妨げないか確かめる。

- `-OutDir` は出力先のフォルダを指定する。相対パスは実行時のカレントディレクトリから解決し、出力先フォルダがなければ作成する。
- `-FileName` は出力するファイルの名前（拡張子 `.xlsm` を含む）。省略時は作業ブックと同じ名前になる（`tool/tool.xlsm` なら `tool.xlsm`）。例外として、作業ブックの名前が `workbook.xlsm` の時は、ブックのフォルダ名を使う（`tool/workbook.xlsm` なら `tool.xlsm`）。
- 出力先に同名のファイルがある場合は、`-Force` を付けたときだけ上書きする。

出力後は、配布用のブックの `VBProject.Protection` が `1`、作業ブックが `0` であることを、`Invoke-ExcelScript.ps1` で読み戻して確かめる。
