# 段階2の起こし方を会話から通す

[ROADMAP](../../ROADMAP.md)の段階2の完了の根拠を確かめた記録です。要件の[起こし方](../requirements.md#確かめ方)のうち、テストを使わない4つと、マクロの実行での実行時エラー・コンパイルエラー・終わらないマクロを、開発版のプラグインの会話から通しました。
確かめた日は2026-11-04です。

## 版

- Windows 11 Pro 10.0.26300、Claude Codeのデスクトップアプリ（Codeタブ）、auto mode
- ビルド: `df0a9d3-dirty-20261104T044545Z`（会話A・会話Bの`server_info`）
- Microsoft 365 Excel 64-bit 16.0.20527.20112。`AccessVBOM`は1、`VBAWarnings`は2

## 再現の手順

- 捨てる前提のアプリのフォルダ`.xlwright/scratch/stage1/`（Git管理外）を使います。`src/modules`に`Calc.bas`（`Forever`）、`Errors.bas`（`Divide`: 0で割る）、`Broken.bas`（`Bad`: 宣言の無い変数）を置きます。
- 元の会話から`start_session`で会話Aと会話Bを始め、手順をメッセージで送ります。元の会話のサーバーは古いビルドのため、Excelの操作には使いません。
- 人の操作は、1回の席で順に行いました。
- 各手順の前後で、`EXCEL.EXE`のプロセスと所有記録を照会します。

## 判定

### マクロの実行での3つのエラー

支持（各1回、会話A）。

- 実行時エラー（`Errors.Divide`）: `EXCEL_ERROR`・`MACRO_ERROR`、`data.number`は11。セッションは`ready`のままで、`session_status`も`ready`だった。
- コンパイルエラー（`Broken.Bad`）: `STATE_UNKNOWN`・`DIALOG`。`data.dialog`に題名と本文が入り、`excel_ended`と`restartable`はともに真だった。開始し直せた。
- 終わらないマクロ（`Calc.Forever`、5秒）: `STATE_UNKNOWN`・`TIMEOUT`。`excel_ended`と`restartable`はともに真で、開始し直せた。
- どの失敗にも`data.log`があり、記録のファイルを指した。

### 会話Aの作業中に、会話Bで同じ主ブックのセッションを開始する

支持（1回）。会話Bの`session_start`は`CONFLICT`・`SESSION_IN_USE`で止まった。その後、会話Aは`range_write`・`range_read`・`session_end`を続けられた。

### 会話Aの作業中に、人がリポジトリの外のブックをエクスプローラーから開き、編集・保存する

支持（1回）。日常のExcelを起動していない状態で、人が開いたブックは新しいExcelで開いた。そのコマンドラインは、ブックのパスだけで`/automation`を含まなかった。人は編集して保存した。その間も会話Aは読み書きを続け、`session_end`（開いているブックの照合を含む）が成功した。

### 主ブックを日常のExcelで編集できる状態で開いたまま、会話Bで開始する

支持（1回）。会話Bの`session_start`は`CONFLICT`・`WORKBOOK_IN_USE`で止まり、閉じるよう`message`で知らせた。専用のExcelは起動しなかった。主ブックは、すでに動いていた日常のExcelに開かれた。

### 会話Aを作業の途中で閉じ、人が主ブックを読み取り専用で開き、その後に会話Bで開始する

支持（1回）。

1. 会話Aで`session_start`し、`session_end`を呼ばずに会話をアーカイブで閉じた。専用のExcel（PID 20580）が残り、所有記録は`owned`だった。
2. 人が主ブックをエクスプローラーから開いた。主ブックは、すでに動いていた日常のExcelに入り、専用のExcelには入らなかった。人は中身を読み取り専用で見られた。
3. 人が読み取り専用で開いたまま、会話Bで`session_start`した。成功し、`cleanup`（PID 20580、`ended_by`は`terminate`）を返した。診断の記録で、開始から新しい専用のExcelの起動まで約10秒だった。会話Aの保存していない変更（C1）は、読み直すと無かった。

### 専用のExcelが主ブックを開いている時に、人が日常のExcelで開くダイアログ

支持（1回）。会話Bが主ブックを開いたままの時に、人がエクスプローラーから開くと、題名「使用中のファイル」のダイアログが出た。

- 本文は、ブックが編集のためロックされていること、使用者のユーザー名、読み取り専用で開くか、通知を受け取るかの案内だった。
- ボタンは「読み取り専用」「通知」「キャンセル」の3つだった。
- 「読み取り専用」で開くと、題名に「読み取り専用」と出て、中身が見えた。マクロはセキュリティの警告のバーで無効だった。
