# ツールのブックの置き場と名前

- Date: 2026-11-20
- 出典: 人との相談で決めた。配置の正本は `plugins/xlwright/skills/xlwright/SKILL.md` の「対象と作業手順」で、ここでは繰り返さない。

新しく作るツールは `src/excel/<ツール名>/workbook.xlsm` に置き、配布用のブックは `dist/<ツール名>.xlsm` に出力する。

## src/excel/ に置く理由

- ブック、VBA のソース、リボンの XML は、原本として管理するものなので `src/` に置く。
- `excel/` で、同じ repo の Excel でないコードと分ける。
- ツールが 1 つでも `<ツール名>/` を掘る。ツールが増えた時に、既にあるツールを動かさずに済む。

## ブックの名前を workbook.xlsm にする理由

Excel は、同じ名前のブックを同時に開けない。どの名前にしても、どこかの組み合わせが同時に開けなくなる。

| ブックの名前 | `src/` の作業ブックと `dist/` の配布物 | `src/` の 2 つのツール |
| --- | --- | --- |
| `workbook.xlsm` | 名前が違うので、同時に開ける | 同じ名前なので、同時に開けない |
| `<ツール名>.xlsm` | 同じ名前なので、同時に開けない | 名前が違うので、同時に開ける |

作業ブックと配布物を並べて、ロックやリボンを見比べる方が、別のツールどうしを並べるより多いと見て、`workbook.xlsm` にした。ほかにも次の利点がある。

- ツールの名前を変える時に、フォルダ名だけを変えればよい。
- `Publish-Workbook.ps1` は、作業ブックが `workbook.xlsm` の時にフォルダ名を出力の名前にする。`-FileName` を渡さなくても、配布物がツール名になる。

失うものは、人の Excel で `src/` の複数のツールを並べて開けないことと、タイトルバーや最近使ったファイルの一覧でツールを名前で見分けられないこと。ツールどうしが参照し合う repo では、これが効く。

## 以前の形

`src/excel/<ブック名>/workbook.xlsm` は、このスキルの元になった `excel-com` スキルの形だった（commit `733b1d4` の `references/excel-com-rebuild.md`）。元のスキルは、その repo の `AGENTS.md` の規則に従っていた。このスキルは最初の commit から置き場を決めず、図のブックを `<ブック>.xlsm` にしていた。そうした理由は記録に残っていない。
