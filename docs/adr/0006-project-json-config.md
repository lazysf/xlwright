# 0006: 利用プロジェクトの設定をproject.jsonにする

- Status: Accepted

2026-11-01に、T16でユーザーが承認しました。
利用プロジェクトの設定ファイルを`project.yaml`から`project.json`へ変えます。
キー・既定値・検証の規則は変えません。規則は[設計](../architecture.md#ブックとソース)にあります。

## 背景

`session_start`は設定を検証してから開始します。
YAMLの解析器は.NETの標準ライブラリになく、リポジトリにも依存がありません。
設定はパスの5項目だけです。
ユーザーは、形式を問わず、完成時に過剰な依存がないことを条件にしました。

## 検討した代替案

`project.yaml`を維持し、YAMLの解析器を依存に加える案を比較しました。
人が書きやすく、コメントも書けます。
一方で、5つの文字列を読むために依存を1つ加えることになります。
`System.Text.Json`は追加の依存なしで、厳密な解析と未知のキーの拒否を満たせます。

## 影響

設定ファイルにコメントを書けません。
製品は未実装のため、既存の利用プロジェクトとの互換は問題になりません。
重複したキーの拒否を標準のオプションで実現できるかは、実装時に確認します。
