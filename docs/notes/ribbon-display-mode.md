# リボンの表示の設定とリボンのスクリプト

- Date: 2026-11-20
- 出典: 人が Excel のリボンの表示を切り替えた後に、一時フォルダのブックで `Test-RibbonLayout.ps1 -ScreenshotDir` と `Invoke-RibbonButton.ps1` を流した実測。Excel 16.0.20527.20196、Windows 11、Windows PowerShell 5.1.26100.9818。

`Test-RibbonLayout.ps1` は、タブの中身の高さが 60 px 未満の時に、簡易表示（単一行）のリボンと見なして終了コード 2 で止まる。測った Excel には単一行のリボンを選ぶ設定が無く、この見分けは確かめられなかった。代わりに選べる表示のうち、「タブのみを表示する」では見分けが働かず、画像にリボンが写らなかった。「全画面表示モード」では、タブが見つからずに止まった。

## 選べた表示

リボンの表示の設定（人が開いたメニューの画像で確かめた）は、「全画面表示モード」「タブのみを表示する」「常にリボンを表示する」の 3 つだった。この設定は人の Excel の設定で、自動化で起動した Excel にも引き継がれたと見ている。切り替えるたびに結果が変わったためで、自動化の側から設定の値は読んでいない。

## 結果

toggleButton、menu、dropDown を 1 つのグループに持つタブで流した。

| 表示 | タブの中身の高さ | `Test-RibbonLayout.ps1` | `tab-1.png` |
| --- | --- | --- | --- |
| 常にリボンを表示する | 101 px | 終了コード 0、食い違い 0 | リボンが写った（表示を戻した後に 2 回） |
| タブのみを表示する | 101 px | 終了コード 0、食い違い 0 | リボンが写らず、数式バーとセルだけ |
| 全画面表示モード | - | 終了コード 2、`No ribbon tab found. Is the ribbon collapsed or hidden?` | 撮られない |

- 「タブのみを表示する」でも、タブを選ぶとタブの中身が UI Automation に出て、高さも同じだった。そのため、照合は通り、見分けは働かない。
- 画像は Excel のウィンドウに描かせて撮る（`PrintWindow`）。「タブのみを表示する」の画像は、タブの中身の位置に数式バーが写っていた。タブを選んだ時に出る中身はウィンドウの描画に入らず、描画ではリボンの中身が無いまま数式バーが詰まっていると推測している。
- 「常にリボンを表示する」で、ウィンドウ全体を撮った画像では、UI Automation のタブの中身の位置とリボンの位置が合っていた。タブを選んですぐ撮っても、0.8 秒待って撮っても同じだった。
- 「全画面表示モード」では、`Invoke-RibbonButton.ps1` も終了コード 1、`Not found: tab 'ExpTab'` で止まった。`Error` には、表示の設定を疑う手がかりが出ない。
- 「タブのみを表示する」での `Invoke-RibbonButton.ps1` は試していない。

## 未確認

- 単一行のリボンを持つ Excel での、60 px の見分け。
- 「タブのみを表示する」を、自動化の側から見分ける方法。
